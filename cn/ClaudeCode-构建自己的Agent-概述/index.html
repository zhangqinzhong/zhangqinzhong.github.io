构建自己的 Agent

Posted by zhangqinzhong on 2026-06-13
Estimated Reading Time 3 Minutes
Words 936 In Total
Viewed Times

用这份文档里的知识，从零开始构建一个真正能工作的 Agent。

学完这个章节，你能做到

  • 理解 Agent 和普通 AI 对话的本质区别
  • 用 50 行代码跑通一个能使用工具的 Agent
  • 设计出行为可控、安全可靠的工具系统
  • 写出真正管用的系统提示词，而不是随便写一句
  • 让 Agent 处理长对话而不崩溃
  • 处理工具失败、API 超时等生产环境问题
  • 让 Agent 跨会话持久化，支持 --resume
  • 协调多个 Agent 并行工作
  • 获取结构化输出（JSON Schema 强制）
  • 控制成本和速率限制
  • 知道哪些 CC 的设计值得复制，哪些可以跳过
