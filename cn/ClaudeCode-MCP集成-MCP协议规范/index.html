协议定位

MCP（Model Context Protocol）是连接 AI 应用与外部系统的开放标准。设计目标是成为"AI 应用的 USB-C 接口"——任何 MCP 客户端（如 Claude Code、Claude Desktop、Cursor）都能无需定制代码地接入任何 MCP 服务器。

与 OpenAI Function Calling 的核心区别：

特性 MCP Function Calling
架构 完整的客户端-服务器协议 API 参数方案
连接 有状态、持久会话 无状态 API 调用
工具发现 运行时动态发现 硬编码在请求参数中
服务器能力 可向客户端请求 LLM 采样、用户输入 单向通信
资源原语 一等公民 不支持
提示词模板 原生支持（Prompts） 不支持

三层架构

关键约束： 每个 Client 只与一个 Server 通信，实现安全隔离。
