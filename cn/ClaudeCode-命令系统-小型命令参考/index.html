斜杠命令完整参考

Posted by zhangqinzhong on 2026-06-19
Estimated Reading Time 5 Minutes
Words 1.3k In Total
Viewed Times

CC 内置约 64 个斜杠命令，分为 local（纯逻辑）、local-jsx（带 React UI）、prompt（Skill 展开）三种类型。本文档覆盖所有未单独成文的命令。

会话与对话管理

/clear

清除当前对话历史，保留系统配置。

与 /compact 的区别：/compact 保留 AI 摘要，/clear 完全清空。

/copy

把最后一条 assistant 回复复制到系统剪贴板。

/rename <新标题>

重命名当前会话，影响 /resume 时的列表显示。

/resume

恢复历史会话。不带参数显示最近会话列表；带 session-id 直接恢复。

/diff

展示当前工作区所有未提交的变更（git diff）。

/context

显示上下文窗口可视化网格（哪些内容占了多少 token）。

/status

显示完整系统状态：连接的 MCP 服务器、权限模式、当前模型、会话 ID 等。

/rewind

交互式选择历史检查点，回滚对话和文件状态到某个时间点。

/export

导出当前对话为 Markdown 文件或复制到剪贴板。

配置与设置

/config

打开交互式配置面板，可设置模型、权限模式、主题等所有选项。

/theme

交互式切换终端颜色主题（dark / light / solarized / dracula 等）。

/vim

在 Vim 编辑模式和普通模式之间切换。

等价于 claude config set editorMode vim。

/keybindings

创建并用系统编辑器打开 ~/.claude/keybindings.json。

/model [模型名]

查看或切换当前使用的模型。

/effort [level]

设置 thinking token 预算级别。

账户与认证

/login

登录或切换账户（Claude.ai OAuth 或 API Key 输入）。

/logout

退出账户，清除本地存储的 Token 和 API Key。

/cost

查看当前会话费用或订阅使用情况。

/usage

显示速率限制使用情况和重置时间。

/privacy-settings

跳转浏览器打开 Anthropic 隐私设置页面。

工具与集成管理

/mcp

MCP 服务器管理面板——查看连接状态、添加/删除服务器。

/ide

IDE 集成管理——安装/查看 VS Code 和 JetBrains 扩展状态。

/plugin

插件管理面板——浏览市场、安装/卸载插件。

/reload-plugins

在当前会话激活最新安装的插件，不需要重启 CC。

/skills

列出当前可用的所有 Skill（内置 + 自定义）。

/hooks

交互式配置 Hook 事件处理器（PreToolUse、PostToolUse 等）。

代码与工作区

/files

列出当前上下文中 CC 知道的所有文件。

/add-dir <路径>

将额外目录添加到允许的工作目录范围。

/permissions

交互式管理工具权限规则（allow / deny 列表）。

/memory

在系统编辑器中打开 ~/.claude/CLAUDE.md（用户级记忆文件）。

/doctor

运行安装诊断，检查 API Key、MCP 连接、快捷键配置等是否正确。

计划与任务

/plan

进入 Plan 模式——CC 生成实现方案但不执行，等待用户审批。

/tasks

后台任务管理面板。

信息与帮助

/help

显示所有可用命令和快捷键。

/release-notes

查看当前版本的更新日志。

/stats

显示使用统计（总会话数、token 使用量、最常用工具等）。

快速功能

/fast

在快速模式（减少 thinking）和标准模式之间切换。

/btw <问题>

快速提问，不打断主对话流。

/color <颜色>

改变当前会话提示栏颜色（多窗口时方便区分）。

集成与应用

/session

生成当前会话的可分享 URL 或二维码（在另一设备继续）。

/desktop

在 Claude Desktop 应用中打开并继续当前会话。

/mobile

生成二维码，在手机上继续当前会话。

/install-github-app

安装 CC 的 GitHub Actions 集成，配置自动代码审查。

/install-slack-app

安装 CC 的 Slack 应用集成。

/feedback [内容]

提交反馈或 bug 报告。

终端设置

/terminal-setup

安装终端快捷键配置（修改 .zshrc / .bashrc 等）。

/statusline

配置 IDE 状态栏集成（VS Code / JetBrains 底部状态栏显示）。

退出

/exit

退出 CC REPL，等价于 Ctrl+D。

命令类型说明

类型 说明 代表命令
local 纯逻辑，同步执行 /clear、/cost、/copy
local-jsx 带 React UI 的交互界面 /config、/mcp、/plugin、/theme
prompt Skill 展开为提示词注入对话 自定义 skill

local-jsx 命令在管道模式（-p）下不可用（supportsNonInteractive: false）。
