Estimated Reading Time 3 Minutes
Words 909 In Total
Viewed Times

概述

services/compact/autoCompact.ts（351 行）实现了 CC 的自动触发上下文压缩机制——当 token 用量接近上下文窗口上限时，在下一次 API 调用前自动触发压缩，无需用户手动执行 /compact。

断路器（Circuit Breaker）

设计背景：数据驱动。BigQuery 发现了大量"无限重试"的失败会话，说明某些情况下上下文已超出可压缩的范围，继续重试只是浪费 API 调用。断路器在 3 次失败后放弃，保存用户配额。

自动压缩的禁用机制

方式 效果
DISABLE_COMPACT=1 禁用所有压缩（包括 /compact 命令）
DISABLE_AUTO_COMPACT=1 只禁用自动压缩（保留手动 /compact）
userConfig.autoCompactEnabled = false 用户设置禁用自动压缩

测试辅助

RecompactionInfo：二次压缩追踪

这些信息传入 compactConversation() 并记录到 analytics，帮助 Anthropic 了解用户的压缩模式（多频繁、连续压缩了几次）。
