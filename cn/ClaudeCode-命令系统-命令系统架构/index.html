概述

CC 的斜杠命令系统（/command）是用户与 Claude 交互的高级接口，位于 src/commands/ 目录（60+ 个命令实现，约 14,592 行核心代码）。命令本质上是预定义 prompt 的发射器——每个斜杠命令最终都变成一个 Claude API 请求，携带精心设计的系统 prompt 和工具限制。

三种命令类型

PromptCommand

典型例子：/commit、/init、/security-review

LocalCommand

典型例子：/compact（本地执行压缩逻辑，不生成新 prompt）、/clear（清空对话）

SlashSkillCommand

用户在 .claude/skills/<name>/SKILL.md 定义的技能，启动时动态加载。

命令注册与路由

内置命令分类

会话控制

命令 类型 功能
/compact Local 压缩对话历史
/clear Local 清空对话
/exit Local 退出 CC
/resume Local 恢复历史会话

代码操作

命令 类型 功能
/commit Prompt 智能 git commit
/commit-push-pr Prompt commit + push + 创建 PR
/security-review Prompt 安全审查当前分支变更
/review Prompt 代码 review

项目初始化

命令 类型 功能
/init Prompt 生成 CLAUDE.md（三阶段交互）
/init-verifiers Prompt 创建验证器技能

分析与洞察

命令 类型 功能
/insights Local 分析所有历史会话（Opus）
/cost Local 查看当前会话费用
/stats Local 查看 token 统计
/usage Local 查看历史用量

配置

命令 类型 功能
/model Local 切换模型
/config Local 配置管理
/vim Local 切换 Vim 模式
/theme Local 切换配色主题

MCP / 插件

命令 类型 功能
/mcp Local 管理 MCP 连接
/plugin Local 管理插件
