Lombok v1.18.20 支持 JDK 16 开箱即用

Lombok 正在使用反射访问内部 JDK API，在以前的 Java 版本中，这会导致警告消息，现在会导致硬错误。

升级lombok版本：

升级 lombok 版本1.18.20为我修复它。因此，如果您可以升级 lombok，我建议您这样做。
