输入预测提示词（Prompt Suggestion）

Posted by zhangqinzhong on 2026-06-04
Estimated Reading Time 2 Minutes
Words 611 In Total
Viewed Times

概述

services/PromptSuggestion/promptSuggestion.ts 实现了输入预测功能：根据当前对话，预测用户下一步可能输入什么，显示为键盘上方的建议（类似手机输入法的联想词）。

完整原文

核心设计思路

“预测用户想法，不是给建议”

这是个微妙但关键的区别：

  • 建议（Claude 视角）：“你应该先写单元测试”
  • 预测（用户视角）：“下一步运行测试” → 用户原本就打算这样做

“宁愿沉默，不要猜错”

用户正在思考如何处理错误时，给个错误的建议反而打断思路。这种设计让建议只在"显而易见"时出现，避免成为噪音。

技术实现

使用 Fork 机制，与主会话共享 prompt cache 前缀，几乎零额外成本。

加载逻辑

  • 默认启用（promptSuggestionEnabled !== false）
  • 通过环境变量 CLAUDE_CODE_ENABLE_PROMPT_SUGGESTION 可覆盖
  • 目前处于 A/B 测试阶段

依赖关系与互动

  • 与 Prompt Cache 互动：Fork 子 Agent 复用父会话的缓存前缀，每次预测的边际成本约为 0
  • 与 REPL 界面互动：建议文字显示在输入框上方，用户按 Tab 或点击接受
