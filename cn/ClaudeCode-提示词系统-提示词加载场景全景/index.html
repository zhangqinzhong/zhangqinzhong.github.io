场景 1：普通交互会话（REPL）

触发条件： 正常启动 claude 命令，交互式输入

条件开关：

组件 加载条件 不加载条件
③ 任务执行规范 默认 outputStyle.keepCodingInstructions=false
⑨ 记忆文件 ~/.claude/memory/ 有内容 CLAUDE_CODE_DISABLE_AUTO_MEMORY=1
⑪ 语言偏好 settings.language 已设置 未设置
⑬ MCP 说明 有 MCP 服务器已连接且提供 instructions 无连接或无 instructions
⑯ CLAUDE.md 存在 CLAUDE.md 文件 CLAUDE_CODE_DISABLE_CLAUDE_MDS=1
⑱ Git 状态 当前目录是 git 仓库 非 git 仓库、Remote Control 模式

场景 2：子 Agent（通过 AgentTool 调用）

触发条件： Claude 调用 AgentTool，创建子 Agent

与主会话的关键差异：

  • 没有 CLAUDE.md（子 Agent 不需要了解整个项目约定）
  • 没有 git 状态（减少上下文，聚焦于分配的任务）
  • 工具集可能被限制（如 Explore Agent 只有只读工具）
  • 有"任务完成后报告摘要"的明确指令

场景 3：Plan Mode（规划模式）

触发条件： Claude 调用 EnterPlanModeTool

要点： Plan Mode 不改变系统提示词，它改变的是权限上下文（PermissionMode）。EnterPlanModeTool 通过 contextModifier 修改 ToolUseContext。

场景 4：KAIROS 自主模式

触发条件： feature('KAIROS') + isProactiveActive() 为 true

与普通会话的关键差异：

  • 完全不同的开场白（自主 Agent vs 编程助手）
  • 包含 tick 循环规则和自主行动规范
  • BriefTool 是主要输出通道（普通输出不展示给用户）
  • SleepTool 用于控制节奏

场景 5：YOLO 分类器（Auto 权限模式的决策）

触发条件： 权限模式为 auto，工具调用需要判断是否自动允许

特殊之处：

  • 1 小时 Cache TTL（而非普通的 5 分钟）
  • 系统提示词从外部 txt 文件加载（可企业定制）
  • 完全与主对话隔离，不影响对话历史

场景 6：SDK / 管道模式（非交互）

触发条件： claude -p "..." 管道模式，或通过 SDK 调用

场景 7：压缩摘要子调用（autocompact 触发时）

触发条件： 对话 token 达到 ~95%，autocompact 自动触发

特殊之处：

  • 没有系统提示词（为了让模型专注于摘要任务）
  • 被明确警告不能调用工具（否则浪费唯一的 turn）

场景 8：记忆提取子 Agent（对话结束后）

触发条件： 对话轮次结束，且主 Agent 自己没有写记忆
