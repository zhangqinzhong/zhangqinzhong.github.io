概述

src/services/mcp/client.ts（3348 行）是 CC 的 MCP 客户端核心，负责建立与外部 MCP 服务器的连接、发现工具、执行工具调用，以及管理连接生命周期（重连、超时、认证）。

七种 Transport 类型

类型 认证方式 典型用途
stdio 无 本地 Node/Python 进程
sse/http OAuth ClaudeAuthProvider 远程 MCP SaaS 服务
sse-ide/ws-ide IDE Auth Token VS Code / JetBrains 扩展
ws Session Ingress Token 内部服务
claudeai-proxy Claude.ai OAuth claude.ai 托管工具
