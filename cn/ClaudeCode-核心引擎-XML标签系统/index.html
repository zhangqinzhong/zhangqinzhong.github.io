XML 标签系统

Estimated Reading Time 2 Minutes
Words 697 In Total
Viewed Times

概述

constants/xml.ts（86 行）定义了 CC 消息系统中使用的所有 XML 标签名常量。CC 使用 XML 标签在用户消息中嵌入结构化上下文，让 Claude 能区分”用户的真实话语”和”系统注入的信息”。

为什么用 XML 标签

Claude 被训练为理解 XML 格式的结构化信息。相比 JSON 或其他格式：

  • 与系统 prompt 中的其他 XML 结构保持一致
  • Claude 能自然理解标签语义
  • 便于在 UI 中折叠/展开（标签名 → 渲染组件）

标签分类

终端输出标签
