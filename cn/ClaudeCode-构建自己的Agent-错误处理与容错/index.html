为什么错误处理是 Agent 的关键

Chatbot 出错就出错了，用户重新问一遍。Agent 不行——它在执行一系列步骤，中间出错可能：

  • 留下半完成的文件修改
  • 无限重试同一个失败操作
  • 吃掉 API 配额但什么都没做完

健壮的错误处理是 Agent 从"原型"到"可用"的关键差距。
