常见问题

Q：循环会无限运行吗？

会。设置 maxTurns 是必须的。CC 对于子 Agent 也有 turn budget 限制。

Q：Claude 说"完成了"但任务没完成怎么办？

在工具的返回值里加上验证结果。比如文件修改后，返回修改后的内容摘要，而不只是 "Success"。

Q：一次 API 调用可以有多个工具调用吗？

可以。Claude 可以在一次响应里请求多个 tool_use block。你的循环需要处理这种情况（对所有工具调用返回对应的 tool_result）。
