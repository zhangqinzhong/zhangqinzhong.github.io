/insights 会话分析命令

Viewed Times

概述

/insights（src/commands/insights.ts，3200 行）是 CC 的使用行为分析引擎。它扫描本地（和可选的远程）所有会话 JSONL 文件，通过 7 次 Claude Opus API 调用生成一份分析报告，写成交互式 HTML 文件输出给用户。

功能定位

报告涵盖：

  • 我在做什么类型的工作（项目领域）
  • 我的交互风格（快速提问 vs 迭代对话）
  • 什么工作流对我有效
  • 哪里出现了摩擦（工具错误、反复澄清）
  • 对我有用的 CC 功能建议
  • 对 CLAUDE.md 的具体建议

7 次 API 调用详解

# 函数 用途 输入大小 输出
1 extractFacetsFromAPI() 单会话定性分析 会话文本（截断至 30KB） JSON SessionFacets
2 generateSectionInsight(project_areas) 工作领域 聚合数据 + facet 摘要 JSON
3 generateSectionInsight(interaction_style) 交互风格 同上 JSON
4 generateSectionInsight(what_works) 有效工作流 同上 JSON
5 generateSectionInsight(friction_analysis) 摩擦点 同上 JSON
6 generateSectionInsight(suggestions) 功能建议 同上 JSON
7 generateSectionInsight(on_the_horizon) 未来机遇 同上 JSON

调用 #2~#7 并行执行，总延迟 ≈ 最慢的那一个（通常 10~20 秒）。
