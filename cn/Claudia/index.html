Claudia：一个会记人、记事的 AI 幕僚长

Claudia 是一个运行在 Claude Code 上的终端 AI 助手，定位是"幕僚长/个人参谋长"。跟那些写好代码就忘的编码代理不同，它的设计核心是跨会话记忆。

它能做什么

记住三样东西：你认识的人、你做的承诺、你怎么做事。

比如你跟 Claude Code 说了句：“我跟 Sarah Chen 上周聊过，答应周五发给她更新版 pitch deck。” 普通对话机器人周五之前就忘干净了。Claudia 会记下来，周五早上提醒你。

它还会追关系健康度。某个联系人 18 天没联系了？提醒你。同一类错误犯了两次？指出来。接的新承诺太多没关旧的？预警。

工作机制

分两层：

模板层（Markdown）：45 个技能文件，Claude Code 启动时读取。包括承诺检测、模式识别、判断感知、风险预警等。用户可调用 /morning-brief、/research、/meeting-prep、/capture-meeting 等命令。

记忆系统（Python）：独立的守护进程，跑在 SQLite 上。两种运行模式：

  • MCP daemon — per-session（stdio），提供约 33 个记忆工具给 Claude Code 调用
  • Standalone daemon — 24/7 运行（LaunchAgent），即使不跟 Claude Code 对话也在后台处理

后台干什么

即使你不开 Claude Code，后台守护进程也在偷跑：

时间 干什么
凌晨 2 点 自适应衰减：旧记忆淡忘，重要记忆衰减减半
凌晨 3 点 合并重复记忆，检测模式，追踪关系
凌晨 3:15 同步到 Obsidian vault
每 6 小时 跨对话趋势检测

语义搜索

记忆搜索不是关键词匹配，而是混合排序：50% 向量相似度 + 25% 重要度 + 10% 新鲜度 + 15% 全文匹配。访问一条记忆会提升它的权重——跟人脑的复述效应差不多。

判断层

你在 /meditate 环节里说过一次"有截止日期的重要收入项目比一般关系维护优先"，它就写进 context/judgment.yaml。以后每天早上简报、承诺检测、风险预警时，这个优先级规则自动生效。

Google Workspace 集成

能连 Gmail、Calendar、Drive、Docs、Sheets 等。有个分档：

  • Core（43 个工具）：Gmail、Calendar、Drive、Contacts
  • Extended（83 个）：加上 Docs、Sheets、Tasks、Chat
  • Complete（111 个）：加上 Slides、Forms、Apps Script

单条命令配置 OAuth，之后就能从邮件里提取承诺、从日历里准备会议简报。

Obsidian Vault

记忆自动投影到 Obsidian vault（~/.claudia/vault/）。新安装默认用 wiki 布局：每个活跃的人、项目、组织各一个页面，每条例证都标注来源记忆。已有的 PARA 用户不受影响。

本质是：SQLite 是数据源，Obsidian 是可浏览、可搜索、可读的投影。

团队调用

背后有两个模型：

  • Haiku — 快速处理文档归档、日程分析
  • Sonnet — 深度研究侦察兵，独立上下文做多轮网络搜索

Claudia 自己保留关系判断和策略决定。

隐私

所有数据存在本地 ~/.claudia/memory/。支持按工作空间隔离，工作记忆和个人记忆分库存储。

需求

Claude Code + Node.js 18+ + Python 3.10+（记忆系统）+ Ollama（embedding，跑 all-minilm:l6-v2）。

macOS、Linux、Windows 都能跑。

安装：npx get-claudia

GitHub 地址：kbanc85/claudia，作者是 Kamil Banc。

如果你是那种"关系多、承诺杂、脑子装不下"的人，这个东西可能比任何 to-do app 都有用。它不是帮你排程，是帮你记住你该记住的。
