概述

utils/classifierApprovals.ts（88 行）和 utils/autoModeDenials.ts（26 行）实现了 CC 的分类器决策追踪系统，记录哪些工具调用被分类器自动批准或拒绝，供 UI 层展示决策原因。

自动模式拒绝日志

拒绝日志在 /permissions 命令的 RecentDenialsTab.tsx 中展示，让用户了解 Auto Mode 拒绝了哪些操作及原因，帮助调试自动化场景。

设计理由：分离追踪

两个系统分离（CLASSIFIER_APPROVALS Map + DENIALS 数组）是因为用途不同：

  • 批准记录：通过 toolUseID 索引，供特定工具调用的 UI 渲染使用，执行完即清除
  • 拒绝日志：时间序列，供审计和调试，最近 20 条
