Command（命令/技能）

类型层次结构

三种命令类型：

  • PromptCommand：Skill（.md 文件展开为提示词），type: 'prompt'
  • LocalCommand：纯逻辑命令（async 函数），type: 'local'
  • LocalJSXCommand：带 React UI 的命令（如 /config 设置界面），type: 'local-jsx'
