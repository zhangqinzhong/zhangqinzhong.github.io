MCP 数据结构完整参考

Posted by zhangqinzhong on 2026-06-28
Estimated Reading Time 9 Minutes
Words 1.9k In Total
Viewed Times

基于 MCP 规范 2025-11-25，覆盖三大核心原语 Tool / Resource / Prompt 的完整 Schema，以及消息内容类型。

Tool（工具）

工具定义

字段说明：

字段 必填 说明
name ✅ 唯一标识符（1-128 字符）
description 推荐 Claude 用这个决定何时调用该工具
inputSchema ✅ JSON Schema 定义参数，Claude 按此填参数
outputSchema — 定义结构化输出格式
title — 人类可读标题（UI 显示）
annotations.readOnly — 标记只读，不会修改数据
annotations.destructive — 标记会删除/覆盖数据，客户端会额外确认

工具调用结果

content 类型汇总：

type 字段 用途
text text: string 纯文本结果
image data: base64, mimeType 图片
resource_link uri, name, mimeType 引用外部资源
resource resource: {uri, text/blob, mimeType} 嵌入资源内容

Resource（资源）

资源定义

资源模板（参数化 URI）

使用 RFC 6570 URI Template 语法。

资源内容（读取结果）

常见 URI Scheme

Scheme 用途
file:// 本地文件系统
git:// Git 版本控制对象
https:// Web 资源
s3:// AWS S3 对象
db:// 数据库记录

Prompt（提示词模板）

提示词定义

提示词内容（获取结果）

Prompt 消息的 content 也支持 image 和 resource 类型，与 Tool 结果相同。

Sampling 消息格式

采样请求

modelPreferences 说明：

  • hints：模型名称偏好（子字符串匹配，按顺序优先）
  • costPriority / speedPriority / intelligencePriority：0-1 的优先级权重

采样响应

stopReason: endTurn | maxTokens | stopSequence | toolUse

Elicitation（用户输入请求）

表单模式

表单支持的字段类型： string、integer/number、boolean、string enum（单选）、array of enum（多选）

action 值：

  • "accept" — 用户确认并提交
  • "decline" — 用户明确拒绝
  • "cancel" — 用户关闭/取消

URL 模式（敏感信息）

通知（Notifications）

MCP 服务器可以主动推送通知，客户端无需轮询：

通知方法 触发时机
notifications/tools/list_changed 工具列表更新
notifications/resources/list_changed 资源列表更新
notifications/resources/updated 特定资源内容更新
notifications/prompts/list_changed 提示词模板更新

完整 API 方法速查

方向 方法 说明
Client→Server initialize 初始化连接
Client→Server tools/list 获取工具列表
Client→Server tools/call 调用工具
Client→Server resources/list 获取资源列表
Client→Server resources/templates/list 获取资源模板
Client→Server resources/read 读取资源内容
Client→Server resources/subscribe 订阅资源变更
Client→Server resources/unsubscribe 取消订阅
Client→Server prompts/list 获取提示词模板列表
Client→Server prompts/get 获取提示词内容
Server→Client sampling/createMessage 请求 LLM 采样
Server→Client roots/list 获取工作区根目录
Server→Client elicitation/create 请求用户输入
