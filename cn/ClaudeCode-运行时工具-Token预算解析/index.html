Estimated Reading Time 2 Minutes

概述

utils/tokenBudget.ts（73 行）实现了 CC 的自然语言 Token 预算解析——用户在消息中输入 +500k 或 use 2M tokens 等表达，CC 解析出精确的 token 数量作为本次会话的输出预算上限。

关键细节：消息末尾是 — do not summarize，明确禁止 Claude 在预算耗尽时开始总结（某些模型会在 token 不够时自动转为总结模式）。

使用场景

用户在消息中指定预算，CC 据此控制本次任务的 token 消耗：

CC 解析 200,000，在 token 用量到达阈值时：

  1. 中断当前输出
  2. 发送 getBudgetContinuationMessage
  3. 继续生成（但 Claude 知道已接近预算）

这是 CC Workflow 工具（/ultraplan）的核心机制之一。
