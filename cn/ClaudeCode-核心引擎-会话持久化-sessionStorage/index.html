概述

utils/sessionStorage.ts（5105 行）实现了 CC 的会话持久化系统。它负责把对话历史写入磁盘（支持 /resume），同时管理会话的元数据、文件历史快照和归因记录。

文件系统布局

project-hash 由原始工作目录的路径 hash 生成，保证同一项目的所有会话在同一目录下。

会话索引与元数据

/resume 命令的实现流程：

  1. 读取 session-list.json 获取所有会话列表
  2. 如果有搜索词，用 agenticSessionSearch（AI）找匹配的会话
  3. 用户选择后，加载对应的 JSONL 文件
  4. 从 compact_boundary 后的位置开始恢复

这是 /undo 功能的数据基础——快照记录了每次对话前的文件状态，可以回退到任意历史版本。
