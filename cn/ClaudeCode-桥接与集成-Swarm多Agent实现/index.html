概述

utils/swarm/（7548 行，15 文件）实现了 CC 的多 Agent 并行协作系统。这里的代码解决了在单个进程内并发运行多个 AI Agent 的核心工程问题：上下文隔离、权限委托、消息传递、生命周期管理。

Idle 状态机

Idle 不是结束，而是等待。这让 Team Lead 可以动态分配任务。

permissionSync.ts（928行）：权限委托协议

与单 Agent AgentTool 的区别

普通 AgentTool Swarm Agent
并发 顺序等待 真正并行
上下文 继承父 Agent 独立（AsyncLocalStorage 隔离）
通信 无 SendMessageTool + 消息队列
权限 子 Agent 的弹窗 委托给 Leader
状态 setAppState 是 no-op 有自己的 AppState
生命周期 任务完成即结束 Idle 等待，可重用
