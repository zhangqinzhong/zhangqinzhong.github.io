概述

Claude Code 是一个运行在终端里的 AI 编程助手。它的核心是一个对话 + 工具调用循环：用户输入 → 调用 Claude API → API 返回工具调用指令 → 执行工具 → 把结果反馈给 API → 继续循环，直到任务完成。

整个系统由五个主要层组成，从外到内依次是：

各层职责

交互层

负责接收用户输入、渲染输出、处理权限弹窗和快捷键。

模块 文件 职责
REPL 界面 screens/REPL.tsx 交互式终端，React + Ink 渲染
管道模式 entrypoints/cli.tsx echo "..." \| claude -p，无交互
SDK 模式 entrypoints/sdk/ 供外部程序调用
启动入口 entrypoints/cli.tsx 参数解析、快速路径（–version 等）
CLI 定义 main.tsx Commander.js 命令注册，服务初始化

引擎层

系统的心脏，驱动整个对话和工具调用循环。

模块 文件 职责
对话循环 query.ts 发送 API 请求、处理流式响应、调用工具、循环直到完成
会话引擎 QueryEngine.ts 管理对话历史、触发压缩、文件快照、commit 归因

工具层

Claude 能做的一切事情都通过工具实现。

模块 文件 职责
工具接口 Tool.ts 定义 Tool 类型和 ToolUseContext
工具注册 tools.ts 组装工具列表，feature flag 控制
工具实现 tools/*/ ~25 个工具，每个一个目录

API 层

与 Claude API（以及 Bedrock / Vertex / Azure）通信。

模块 文件 职责
API 客户端 services/api/claude.ts 构建请求参数、处理流式事件、prompt cache
提供商路由 utils/model/providers.ts 根据配置选择 Anthropic / AWS / GCP / Azure
错误处理 services/api/errors.ts 重试逻辑、速率限制、上下文溢出

基础设施层

贯穿所有层的横切关注点。

模块 路径 职责
权限系统 hooks/toolPermission/ 每次工具调用前的 allow/deny/ask 判断
Hook 系统 hooks/ 用户配置的前置/后置 shell 钩子
MCP 集成 services/mcp/ 连接外部 MCP 服务器，扩展工具集
自动压缩 services/compact/ 上下文接近上限时压缩历史消息
记忆系统 memdir/ 持久化记忆文件注入系统提示词
状态管理 state/AppState.tsx 全局 UI 状态，React Context

关键设计决策

1. 工具调用是单线程串行的（默认）

query.ts 的工具调用循环默认串行执行。Claude 也可以在一次响应里请求多个工具调用，这些会并发执行——但前提是工具的 isConcurrencySafe() 返回 true。

2. 提示词分静态和动态两层

为了充分利用 Anthropic 的 Prompt Cache（缓存命中可降低 90% 成本），系统提示词被拆分：

  • 静态层：角色定义、操作规范等不变内容 → 全局缓存
  • 动态层：git status、CLAUDE.md、MCP 连接状态 → 每次生成

两层之间有明确的边界标记 __SYSTEM_PROMPT_DYNAMIC_BOUNDARY__。

3. 工具即一切

Claude Code 几乎所有能力都通过工具实现，包括：

  • 文件读写（不是直接调 fs，是 FileReadTool / FileWriteTool）
  • 执行命令（BashTool）
  • 与用户交互（AskUserQuestionTool）
  • 启动子 Agent（AgentTool）
  • 管理任务（TaskCreateTool / TaskUpdateTool）

这个设计让权限检查、日志记录、UI 渲染可以统一在工具层处理。

4. 运行时是 Bun，不是 Node.js

构建和运行全部使用 Bun：

  • bun:bundle 提供构建时 feature flag（feature('FLAG_NAME')），死代码在打包时被消除
  • bun build 打出单文件 bundle（约 25MB）
  • 依赖 Bun 原生 API（文件 I/O、进程管理）
