系统提示词决定 Agent 的"人格"

同样的工具集，不同的系统提示词，会产生完全不同的 Agent：

  • 一个谨慎确认每步操作的 Agent
  • 一个快速自主完成任务的 Agent
  • 一个专注安全审查的 Agent

系统提示词是控制 Agent 行为最有效的手段。

从 CC 学到的 8 个设计原则

原则 1：先说身份，再说规则

原则 2：工具偏好要明确（双重约束）

CC 在系统提示词和工具 description 里都说了"用 GrepTool 不要用 bash grep"。

为什么两处都要说？因为 Claude 有时只看系统提示词，有时只看工具说明，双重约束更可靠。

原则 3：并行操作要明说

不说这个，Claude 会默认顺序执行，浪费时间。

原则 4：失败处理要规定流程

原则 5：最小化原则防止过度执行

原则 6：不可逆操作要求确认

原则 7：输出要简洁直接

原则 8：给 Claude “借口清单”
