session/update 通知类型

所有通知均为：

agent_message_chunk

字段 类型 说明
type "agent_message_chunk"
messageId string 同条消息的 chunk 共享同一 ID
chunk string 文本片段
isFirst boolean? 第一个 chunk
isFinal boolean? 最后一个 chunk

thought_message_chunk

同 agent_message_chunk 结构，内容为 Agent 推理过程（Extended Thinking）。

tool_call

字段 类型 说明
type "tool_call"
toolCallId string 唯一 ID
title string 展示给用户的标题
kind string read / write / execute / search 等
status "running"
input object 工具调用参数

tool_call_update

字段 类型 说明
type "tool_call_update"
toolCallId string 对应 tool_call 的 ID
status string running / completed / failed
contentChunk string? 进度文本
output object? 完成时的输出
error string? 失败时的错误

plan

available_commands_update

mode_change

Client 侧方法（Agent → Editor）

session/request_permission

fs/read_text_file / fs/write_text_file

terminal/*

错误码

码 含义

-32601 Method not found
-32602 Invalid params
-32603 Internal error
-32001 Session not found
-32002 Permission denied
-32003 Authentication required
